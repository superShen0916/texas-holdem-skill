# 各种玩法

同一个游戏，人数、赛制、筹码深度一变，策略就完全不同。

| 玩法 | 文件 | 核心差异 |
| --- | --- | --- |
| 6-max 现金局 | [`cash-6max.md`](cash-6max.md) | 主流线上赛制，位置最关键，范围最宽 |
| 满员桌现金局 | [`cash-full-ring.md`](cash-full-ring.md) | 9-10 人，牌力要求更严，多人底池多 |
| 锦标赛 MTT | [`mtt.md`](mtt.md) | 盲注上升、ICM、泡沫期，筹码会贬值 |
| 单桌赛 SNG | [`sng.md`](sng.md) | 前期累积、后期推推乐，ICM 影响大 |
| 单挑 Heads-Up | [`heads-up.md`](heads-up.md) | 范围极宽、位置定义不同、动态博弈 |
| 短牌 Short Deck | [`short-deck.md`](short-deck.md) | 去掉 2-5，成牌概率大变 |

## 怎么选

| 想做的事 | 玩哪种 | 置信度 |
| --- | --- | --- |
| 练技术 / 手数多 | 6-max 现金局 | `[共识]` |
| 稳、波动小 | 满员桌现金局 | `[共识]` |
| 学 ICM | SNG | `[共识]` |
| 长期打大赛 | MTT | `[共识]` |
| 练对抗 / 心态 | 单挑 | `[共识]` |
| 换口味 | 短牌 | `[共识]` |

## 通用原则

**筹码越深越靠技术，越浅越靠数学。** 先搞清楚有效筹码深度，再选策略。`[共识]`

> SPR 与筹码深度的对应见 [`reference/spr.md`](../reference/spr.md)。
