# 满员桌现金局（9-10 人）

人多、盲注摊薄，节奏更慢，适合新手练纪律，但也更容易"等半天一手牌"。

## 核心特点

- 人多，平均牌力更强 → **入池要更紧**
- 盲注占总筹码比例低，偷盲收益下降
- 多人底池（3 人以上）更常见 → 坚果价值上升

## 范围调整

在 6-max 范围基础上**整体收紧一档**：
- UTG（9-max 的真正 UTG）≈ 6-max 的 UTG 还要再紧，约 10-12%
- 中位 ≈ 6-max 的 UTG/HJ
- CO/BTN 相对放宽，但比 6-max 同位置紧
- **小对子在前位价值下降**（多人底池深，追 set 赔率不够）→ 前位可弃

## 多人底池原则

- 翻中坚果类（顺子、同花、三条）的价值**大幅上升**
- 诈唬频率**大幅下降**——人多，总有人有牌
- 顶对在多人底池不再强，别拿它打光

## 什么时候该换到 6-max

- 如果你在满员桌一直"等不到牌、赢不到钱"
- 想练手数更多、位置感更快的技术 → 6-max 效率更高
- 满员桌的优势：波动小、鱼相对集中、适合资金不厚时稳打

## 座位选择

- 左手边放松手（你在他们后面行动，能便宜地看他们怎么做）
- 右手边放紧手（偷他们的盲最安全）
- 观察谁在"等走"、谁是常客

## 常见错误

- [ ] 用 6-max 的宽范围打满员桌（入池太松，人多被碾压）
- [ ] 在前位拿小对子追 set（隐含赔率不足）
- [ ] 多人底池里还高频诈唬
