# 锦标赛 MTT

锦标赛和现金局是两个游戏：**筹码会贬值，淘汰不可逆**。

## 核心特点

| 特点 | 含义 | 置信度 |
| --- | --- | --- |
| 盲注持续上涨 | 筹码购买力下降，不能只等好牌 | `[共识]` |
| 淘汰不可逆 | 输了就没了，不能重新买入 | `[共识]` |
| ICM | 跟注付出的还有名次价值 | `[共识]` |

## 阶段策略

| 阶段 | 筹码 | 打法 | 置信度 |
| --- | --- | --- | --- |
| 前期 | 50bb+ | 接近现金局，重视**累积筹码**，可投机 | `[共识]` |
| 中期 | 20-40bb | 抗盲、主动抢盲、隔离、3-bet 偷；收窄跟注 | `[共识]` |
| 后期 / 泡沫 | 10-20bb | 推推乐为主，别打小池 | `[共识]` |
| 决赛桌 | 不定 | ICM 影响最大，见下 | `[共识]` |

## 筹码深度速查

| 深度 | 打法 | 置信度 |
| --- | --- | --- |
| 50bb+ | 正常打，可投机 | `[共识]` |
| 20-40bb | 抗盲、3-bet 偷、收跟注 | `[共识]` |
| 10-20bb | 推推乐为主 | `[共识]` |
| < 10bb | 拿到可推的牌就推，别等死 | `[共识]` |

## ICM 与泡沫

**ICM 原则**：筹码价值递减——**同样多的筹码，你要冒的风险比对手大**。

| 场景 | 调整 | 置信度 |
| --- | --- | --- |
| 大筹码 vs 小筹码全下 | 大筹码的跟注范围要**收缩** | `[共识]` |
| 泡沫期，你是大筹码 | **疯狂施压**（bubble abuse）——对手输不起 | `[共识]` |
| 泡沫期，你是短筹码 | 反而更紧——等别人先出局 | `[共识]` |
| 决赛桌中等筹码 | 最尴尬，最容易成为"人质" | `[共识]` |

> **跟注要严于 MDF**（[`reference/mdf.md`](../reference/mdf.md)），因为 ICM 让输筹码的代价高于赢筹码的收益。`[共识]`

## 卫星赛（Satellite）

| 原则 | 置信度 |
| --- | --- |
| 目标不是第一，是"进名额" | `[共识]` |
| 越接近名额越要**超紧**，让短筹码自相残杀 | `[共识]` |
| 名额确定后，多余筹码价值为零 | `[共识]` |

## 常见错误

- [ ] 前期过紧，中期必然短筹码
- [ ] 泡沫期不敢抢，错失施压机会
- [ ] 忽略 ICM，用 chip EV 做决策
- [ ] 短筹码死等 AA，被盲死
