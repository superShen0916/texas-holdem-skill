# 锦标赛 MTT

锦标赛和现金局是两个游戏：**筹码会贬值，淘汰不可逆**。

## 核心特点

- 盲注持续上涨 → 筹码购买力不断下降，**不能只等好牌**
- 阶段分明：前期（深）→ 中期（抗盲）→ 后期 / 泡沫 → 决赛桌
- **ICM**：跟注付出的不只是一手牌的 chip EV，还有名次价值

## 阶段策略

### 前期（50bb+）
- 接近现金局打，但更重视**累积筹码**（你要做大才有后期资本）
- 可以打更多投机牌、看更多翻牌（人多、隐含赔率好）
- 别用全部筹码去"抢一个小池"

### 中期（20-40bb）
- 进入**抗盲**阶段，主动抢盲、隔离、3-bet 偷
- 收窄跟注范围，扩大**主动下注**范围
- 别让自己被盲注磨到 10bb 以下才行动

### 后期 / 泡沫（10-20bb）
- 推推乐（push/fold）成为主力，背 push/fold 表
- **泡沫期**：短筹码会拼命弃牌想进钱圈 → 用大筹码疯狂施压（bubble abuse）
- 但如果你自己是大短筹码，反而要更紧——等别人先出局

### 决赛桌
- ICM 影响最大：**不轻易用大筹码去跟大筹码的全下**
- 中等筹码最尴尬，最容易成为"人质"
- 短筹码要主动赌一把，别干等

## 筹码深度速查

| 深度 | 打法 |
| --- | --- |
| 50bb+ | 正常打，可投机 |
| 20-40bb | 抗盲、3-bet 偷、收跟注 |
| 10-20bb | 推推乐为主，别打小池 |
| < 10bb | 拿到可推的牌就推，别等死 |

## ICM 与泡沫

- 筹码价值递减：**同样多的筹码，你要冒的风险比对手大**
- 跟注范围要**收缩**——尤其是大筹码跟小筹码全下时
- 反过来说：**大筹码可以毫无顾忌地施压**，因为对手输不起

## 卫星赛（Satellite）

- 目标不是第一，而是"进钱圈"
- 越接近名额，越要**超紧**，让短筹码自相残杀
- 名额确定后，多出来的筹码价值为零

## 常见错误

- [ ] 前期打得过紧，到中期必然短筹码
- [ ] 泡沫期不敢抢，错失施压机会
- [ ] 忽略 ICM，用 chip EV 做决策
- [ ] 短筹码死等 AA，结果被盲死
