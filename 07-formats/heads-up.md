# 单挑 Heads-Up

纯一对一，是扑克里**范围最宽、动态博弈最激烈**的形态。

## 核心特点

- 每手牌**按钮位就是小盲**，位置优势被大幅削弱（翻前先行动，翻后反而后行动）
- 弃牌率过高会被盲注磨死 → 范围必须**极宽**
- 对手会针对你调整，**你要比他调得更快**

## 翻前

- **按钮 / 小盲**：开池范围极宽（60-80%+），尺度 2~2.5bb
- **Limp 战术**：可以混合使用 limp，避免每次都被 3-bet 惩罚
- **大盲**：防守范围也极宽，因为只需再付 0.5-1.5bb

> 单挑里"位置"的定义变了，别把 6-max 的直觉直接搬过来。

## 翻后

- 翻牌面**谁有范围优势**要看牌面：低连面偏大盲，高张面偏按钮
- 小块面：按钮经常 c-bet 小注
- 大块面（A/K/Q）：大盲命中多，按钮要谨慎
- 双方范围都极宽 → 摊牌价值经常就够赢，别乱诈唬

## Limp 战术

- 单挑中 limp 可以：控池、看便宜翻牌、避免被 3-bet
- 配合 limp-raise（用强牌）让对手不敢随便加注
- 别每手都 limp 也别每手都加注，保持不可预测

## 情绪战

- 单挑输赢快、方差大，**最容易上头**
- 连续被 3-bet / 被偷 → 想反击 → 越打越凶 → 崩盘
- 对策：预设止损、保持节奏、别把每一手都当生死战

## 调整节奏（Level War）

- 你调 → 对手再调 → 你再调，循环往复
- 关键：观察对手**什么时候**开始针对你，然后反制
- 常见顺序：他先弃太多 → 你多偷 → 他开始跟 → 你收紧价值 → 他又弃……

## 常见错误

- [ ] 用 6-max 的紧度打单挑（被盲注磨死）
- [ ] 从不 limp，被无限 3-bet
- [ ] 上头后不调整，越输越凶
- [ ] 忽略牌面结构，机械 c-bet
