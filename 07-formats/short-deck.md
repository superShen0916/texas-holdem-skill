# 短牌 Short Deck（6+ Hold'em）

去掉 2、3、4、5，只剩 **36 张**。规则小改，策略大变。

## 核心特点

| 特点 | 含义 | 置信度 |
| --- | --- | --- |
| 牌变少（36 张） | **成牌概率大幅提高** | `[数学]` |
| A6789 顺子合法 | A 可两边连 | `[共识]` |
| 手牌强度整体上移 | 顺子/三条价值升，小对子/弱同花价值降 | `[共识]` |

## 手牌价值重排

| 牌 | 变化 | 原因 | 置信度 |
| --- | --- | --- | --- |
| 小对子（22-66） | **变弱** | set 不再稀有，对手成牌也更容易 | `[共识]` |
| 同花连张（如 89s） | **变强** | 顺子概率大幅上升 | `[共识]` |
| A+K / A+Q | **变强** | A 连两头，成顺机会多 | `[共识]` |
| 弱同花（如 K2s） | 变弱 | 同花不再稀有 | `[共识]` |

## 翻后与尺度

| 结论 | 依据 | 置信度 |
| --- | --- | --- |
| **诈唬更难**（对手总有 equity） | 成牌率高 | `[共识]` |
| **价值下注更容易**（对手总能跟） | 同上 | `[共识]` |
| 但对手的反抗频率也高 | 需要更结实的牌才玩大池 | `[共识]` |

## 规则差异（务必先确认）

| 差异点 | 说明 | 置信度 |
| --- | --- | --- |
| 三条 vs 顺子大小 | **有些场次三条大过顺子，有些相反** | `[共识]` |
| 盲注结构 | 常见 ante + button blind 形式 | `[共识]` |

> **打之前一定确认三条/顺子的大小规则**——不同平台不同。

## 从普通德州转短牌最常见的错

- [ ] 还用小对子把大池
- [ ] 高估同花价值
- [ ] 沿用普通德州的诈唬频率（太频繁 → 被打爆）
- [ ] 没确认三条/顺子大小规则就上场
