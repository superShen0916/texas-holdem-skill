# 短牌 Short Deck（6+ Hold'em）

去掉 2、3、4、5 四种点数的所有牌，只剩 **36 张**。规则小改，策略大变。

## 核心特点

- 牌变少 → **成牌概率大幅提高**（同花、顺子极其常见）
- A6789 顺子合法（A 可以两边连）
- 手牌强度整体上移：小对子、弱同花价值下降，**顺子 / 三条**价值上升
- 常客常说："短牌里同花比三条还弱"

## 手牌价值重排

| 牌 | 变化 | 原因 |
| --- | --- | --- |
| 小对子（22-66） | **变弱** | 翻中 set 概率上升，但对手成牌也更容易，set 不再是坚果 |
| 同花连张（如 89s） | **变强** | 顺子概率大幅上升 |
| A+K / A+Q | **变强** | A 能连两头，成顺子机会多 |
| 弱同花（如 K2s） | 变弱 | 同花不再稀有 |

## 翻后概率的变化

- 翻牌听同花：更少的牌（36 张）→ 成牌概率更高
- 顺子听牌 **极多**（几乎每张牌都连着）
- 意义：**诈唬更难**，因为对手总有 equity；**价值下注更容易**，因为对手总能跟

## 下注尺度

- 因为成牌率高，**大诈唬效果差** → 更偏向价值下注
- 常见策略：高频、较大尺度地下注（对手实在太多牌能扛）
- 但对手的反抗（加注）频率也高 → 需要更结实的牌才敢玩大池

## 规则差异（务必先看清场次）

- **三条 vs 顺子**：有些场次规定三条大过顺子，有些反过来，**打之前一定确认**
- 盲注结构常是 ante + button blind 形式
- 各平台细微规则不同，别想当然

## 从普通德州转短牌最容易犯的错

- [ ] 还用小对子把大池（在这里不够强）
- [ ] 高估同花的价值
- [ ] 沿用普通德州的诈唬频率（太频繁 → 被打爆）
- [ ] 没确认三条 / 顺子的大小规则就上场
