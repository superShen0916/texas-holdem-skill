# 单桌赛 SNG

9 人单桌、涨盲快，是"推推乐"训练场，也是理解 ICM 的最佳入门。

## 核心特点

- 人数少、涨盲快 → 很快从"打牌"过渡到"打筹码"
- 通常前三名有奖，**ICM 影响极大**
- push/fold 表是必修课

## 阶段打法

### 前期（满员，深筹码）
- 还是按现金局打，目标是**累积筹码**、别被盲死
- 可以打投机牌（人多，隐含赔率好）
- 别过早全下送命

### 中期（6-4 人）
- 盲注压力上来，开始**主动抢盲**
- 短筹码进入推推乐
- 有位置时放宽开池

### 泡沫期（4 人抢 3 个名额）
- **大筹码疯狂施压**——其他人都不想成为第 4 名
- 中等筹码最难打，要挑软柿子
- 短筹码死等好牌，但别等到没翻盘机会

### 三人 / 单挑
- 打法完全切换，范围极宽（见 [heads-up.md](heads-up.md)）
- 三人时注意：短筹码最该紧，因为"再等一个就进钱圈"

## ICM 要点

- 每个筹码的名次价值不同 → **不能用 chip EV 决策**
- 越接近钱圈，跟注要求越高
- 用 ICM 计算器 / 表格辅助

## push/fold 速记

短筹码（<10bb）开局全下的大致宽度（仅供参考，需按位置调整）：

| 位置 / 人数 | 可推范围 |
| --- | --- |
| 剩 2 人（BTN/SB） | 很宽，50%+ |
| 剩 3 人 | 放宽，30-40% |
| 剩 6+ 人，后位 | 20-30% |
| 剩 6+ 人，前位 | 10-15% |

## 常见错误

- [ ] 前期太紧，中期被迫推垃圾
- [ ] 泡沫期大筹码反而保守，白白放过施压机会
- [ ] 短筹码干等 AA，被盲注磨死
- [ ] 忽略 ICM，在泡沫期用边缘牌跟注全下
