# 面对下注

**适用**：对手已经下注，轮到你。这是翻后最高频的决策。

数值一律查 [`reference/`](../reference/)，不要算。

---

## 一、三步走

```
① 算所需胜率 → [reference/pot-odds.md](../reference/pot-odds.md)
   看对手下注占底池多少，查表
② 估我的胜率
   听牌 → 数出牌 → [reference/equity.md](../reference/equity.md)
   成牌 → 判断在对手范围里领先多少
③ 比：胜率 > 所需 → 倾向跟；否则弃
```

> **示例**：同花听（9 出牌，35.0%）面对半池下注（所需 25.0%）→ 够跟。

---

## 二、跟 / 弃 / 加：怎么选

| 我的牌 | 默认动作 | 置信度 |
| --- | --- | --- |
| 坚果、接近坚果 | **加注**（价值） | `[共识]` |
| 强牌（两对+） | 加注 或 跟注（看被翻盘风险） | `[共识]` |
| 有权益的听牌 | 跟注；对手常弃牌时改加注（半诈唬） | `[共识]` |
| 中等摊牌价值 | **跟注**，别加注 | `[共识]` |
| 弱摊牌价值（只能赢诈唬） | 按底池赔率决定跟/弃 | `[共识]` |
| 空气 | 弃牌；特定对手可诈唬加注 | `[共识]` |

---

## 三、再加一层 MDF

底池赔率管"我这手牌该不该跟"；MDF 管"我**整个范围**至少该防守多少"。

查 [`reference/mdf.md`](../reference/mdf.md)：

| 对手下注 | 你至少要继续 |
| --- | --- |
| 1/3 池 | 75% |
| 1/2 池 | 66.7% |
| 满池 | 50% |

**用法**：从你范围内的牌按强弱往下排，取到 MDF 线。低于这条线的牌可以弃。

> **关键**：MDF 的前提是"对手会用足够的诈唬惩罚你"。他几乎不诈唬时，你可以**弃得比 MDF 多得多**。见 [`reference/mdf.md`](../reference/mdf.md) 的限制一节。

---

## 四、诈唬抓（Bluff Catch）

**定义**：用一手只能赢对手诈唬、赢不了他价值下注的牌去跟注。

**什么时候抓**：

| 条件 | 置信度 |
| --- | --- |
| 你的牌阻断了对手的价值组合（如你持 A，他少了 AA/AK） | `[共识]` |
| 对手在这个节点有诈唬倾向（HUD 显示高 AF / 高 WWSF） | `[常见]` |
| 赔率给了足够空间（小注时更该抓） | `[数学]` |
| 对手是跟注站 / 从不诈唬 | **别抓** |

**什么时候不抓**：

| 条件 | 置信度 |
| --- | --- |
| 对手是岩石 / 被动型（他下注基本是真有牌） | `[共识]` |
| 多人底池（人多，诈唬概率低） | `[共识]` |
| 你的牌不阻断任何价值组合 | `[常见]` |
| 河牌被对手加注（河牌加注几乎都是真家伙） | `[共识]` |

---

## 五、加注

| 类型 | 用牌 | 尺度 | 置信度 |
| --- | --- | --- | --- |
| **价值加注** | 两对以上 | `≈3 ×` 对手下注 | `[共识]` |
| **半诈唬加注** | 有出牌的听牌 | 同上 | `[共识]` |
| **诈唬加注** | 纯空气 | 只对能弃牌的对手用 | `[常见]` |

**河牌加注**：几乎都是价值。你别用中等牌去跟河牌加注。`[共识]`
