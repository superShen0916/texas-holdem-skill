# 多人底池

**3 人及以上看翻牌**。规则和单挑底池差别很大，最大的区别是：**你的牌被超过的概率随人数上升**。

---

## 一、核心原则

| 原则 | 说明 | 置信度 |
| --- | --- | --- |
| **收紧** | 人多 → 需要更强的牌才值得投入 | `[共识]` |
| **诈唬频率大幅下降** | 人多，总有人有牌 | `[共识]` |
| **价值范围变窄、更坚果** | 只有强牌才做大底池 | `[共识]` |
| **权益实现变差** | 你成牌了，别人也可能成更大的 | `[共识]` |

---

## 二、牌力重估

同一个牌力，多人底池里**价值下降**：

| 牌力 | 单挑 | 多人（3+） | 置信度 |
| --- | --- | --- | --- |
| 顶对 | 强，可以打光 | **不再强，别打光** | `[共识]` |
| 超对（AA/KK） | 很强 | 被追上概率明显上升 | `[共识]` |
| 两对 | 强 | 好，但注意牌面 | `[共识]` |
| 暗三 / 顺子 / 同花 | 坚果级 | **依然强，价值上升** | `[共识]` |

> **记忆**：人越多，越要**追求坚果**。中等牌在多人底池里是陷阱。

---

## 三、行动调整

| 场景 | 调整 | 置信度 |
| --- | --- | --- |
| 你是翻前加注者，多人在场 | c-bet 频率砍半以上，尺度加大 | `[共识]` |
| 你持中等牌 | 过牌，控池，别主动做大 | `[共识]` |
| 你持听牌 | 权益实现差 → 更依赖赔率，少半诈唬 | `[常见]` |
| 面对下注 | 弃牌标准上调（同样的牌在单挑能跟，多人都得弃） | `[共识]` |
| 你持坚果 | 积极做大，别慢打过头 | `[共识]` |

---

## 四、位置在多人底池里更重要

- 有位置 → 能看到前面所有人怎么行动再决定，价值大幅上升
- 无位置 + 多人 → 非常难打，收紧到基本只玩强牌

---

## 五、常见错误

- [ ] 多人底池里用顶对打光
- [ ] 沿用单挑的诈唬频率
- [ ] 用中等牌主动做大底池
- [ ] 忽略了"人多 → 被超过概率高"这个基本事实
