# 心态与资金管理

技术决定能不能赢，心态和资金管理决定能不能一直坐在桌上。

---

## 一、上头（Tilt）：识别与中止

| 信号（出现任一即停） | 置信度 |
| --- | --- |
| 想"把刚才输的赢回来" | `[共识]` |
| 开始打平时不会打的牌 | `[共识]` |
| 加注/诈唬频率明显上升 | `[共识]` |
| 对某对手产生"一定要赢他"的执念 | `[共识]` |
| 心跳加快、坐不住 | `[经验]` |

**中止机制**：

| 措施 | 说明 | 置信度 |
| --- | --- | --- |
| 预设止损点（如输 3 个买入） | 到了无条件走 | `[共识]` |
| 连续 bad beat 后强制休息 15 分钟 | 打断情绪链 | `[共识]` |
| 离桌后不立刻回来 | — | `[共识]` |

> **认账**：上头时做的决策，EV 一定是负的。`[共识]`

## 二、结果导向 vs 过程导向

**一手牌打得好不好，看决策质量，不看结果。**

| 情形 | 判定 |
| --- | --- |
| 90% 胜率被翻盘 | 打得好，运气差 |
| 30% 胜率跟注赢下来 | 打得差，运气好 |

**复盘问法**：当时已知信息下，这是最好的决定吗？（而不是"我赢了吗？"）`[共识]`

## 三、波动的量级

| 事实 | 数值/说明 | 置信度 |
| --- | --- | --- |
| 长期盈利者也可能连续输 | 约 20 个买入 | `[共识]` |
| 胜率 +5bb/100、标准差约 100bb/100 时，确认盈利所需手数 | 约数万手 | `[数学]` |

> **意义**：别用一两周的结果判断水平，更别因此改变有效的策略。`[共识]`

## 四、资金管理

| 玩法 | 建议买入数 | 置信度 |
| --- | --- | --- |
| 现金局（6-max） | 20 – 40 | `[共识]` |

| MTT | 100+ | `[共识]` |
| SNG | 50 – 100 | `[共识]` |

**原则**：

| 原则 | 置信度 |
| --- | --- |
| 资金 = 输得起、不影响生活的钱 | `[共识]` |
| 单次买入 ≤ 总资金的 5% | `[常见]` |
| 用独立资金池，赢了不立刻花掉 | `[共识]` |

## 六、复盘方法

| 步骤 | 做法 | 置信度 |
| --- | --- | --- |
| 1. 记录 | 截图/笔记，重点是**大池**和**拿不准的决策** | `[共识]` |
| 2. 分类 | 哪些是运气，哪些真打错了 | `[共识]` |
| 3. 找漏洞 | 同一错误反复出现 → 优先修 | `[共识]` |
| 4. 定期回顾 | 每周/每月看一次 | `[共识]` |
| 5. 量化 | 看 bb/100、VPIP、3-bet% 是否偏离目标 | `[共识]` |

> **复盘心态**：找自己的错，不是找"运气不好"的借口。`[共识]`
