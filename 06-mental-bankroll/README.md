# 06 心态与资金 Mental Game & Bankroll

技术决定**能不能赢**，心态和资金管理决定**能不能一直坐在桌上**。这两件事往往才是长期结果的真正分水岭。

---

## 情绪管理（Tilt）

**Tilt 的典型信号**（出现任意一条，就该停下来）：
- 想"把刚才输的赢回来"
- 开始打平时不会打的牌（K7o、任意同花）
- 加注 / 诈唬频率明显上升
- 对某个对手产生"一定要赢他"的执念
- 心跳加快、手出汗、坐不住

**中止机制**：
- 预设**止损点**（如输 3 个买入），到了就走，不商量
- 连续 bad beat 后强制休息 15 分钟
- 离桌后不立刻回来，先做点别的事
- 认账：**上头时做的决策，EV 一定是负的**

## 结果导向 vs 过程导向

**一手牌打得好不好，看的是决策质量，不是结果。**

- 90% 胜率被翻盘 → 打得好，运气差
- 30% 胜率跟注赢下来 → 打得差，运气好

**实操方法**：复盘时问自己「在**当时已知信息**下，这是最好的决定吗？」而不是「我赢了吗？」

> 只有过程导向，才能不被波动带偏。

## 波动（Variance）的本质

- 短期的输赢**几乎全是运气**，技术要成千上万手才显现
- 参考：即使长期盈利的玩家，也可能连续输 20 个买入
- 胜率 +5bb/100 的玩家，标准差约 100bb/100 → 需要**几万手**才能以 95% 信心确认自己是赢的

**意义**：不要用一两周的结果判断自己的水平，更不要因此改变有效的策略。

## 资金管理（Bankroll）

技术再强，资金不够也会被波动打爆。

| 玩法 | 建议买入数 |
| --- | --- |
| 现金局（6-max） | 20-40 个买入（激进 20，保守 40） |
| 满员桌现金 | 30-50 个买入 |
| MTT | 100+ 个买入（波动最大） |
| SNG | 50-100 个买入 |

**原则**：
- 资金 = 你**输得起、不影响生活**的钱，绝不挪用生活 / 应急资金
- 单次买入 ≤ 总资金的 5%
- 用**独立**的资金池，别把赢的钱立刻花掉

## 升级 / 降级纪律

- **升级**：在本级别稳定盈利 **N 个买入**后才升级（如 20 个买入）
- **降级**：资金跌到下一级别的门槛就降级，别硬撑
- 别因为「在低级别赢太多、觉得无聊」就往上跳——这是爆仓最常见的路径

## 复盘方法

1. **记录手牌**：截图或笔记，尤其是**大池**和**拿不准的决策**
2. **分类**：哪些是运气，哪些是真的打错了
3. **找漏洞**：同一个错误反复出现 → 优先修
4. **定期回顾**：每周 / 每月看一次自己的记录
5. **量化**：看 bb/100、VPIP、3-bet% 是否偏离自己的目标

**复盘的正确心态**：找自己的错，而不是找"运气不好"的借口。

## 止损止盈与执行

- **止损**：预设金额，到了无条件离桌（**执行比数值更重要**）
- **止盈**：不一定需要，但"赢了就飘、打得放松"很常见 → 可在目标达成后离桌
- **时间止损**：连续打 3 小时以上，决策质量会明显下降，该休息

## 连续不赢 / 被 bad beat 时

- 接受：这是波动的一部分，不是"系统坏了"
- 检查：是运气还是自己真的打错了？用复盘分清
- **不要**：为了"证明自己"而加大赌注、升级别
- 必要时彻底休息几天，回到牌桌时状态会完全不同

## 身体状态与决策质量

- 疲劳、饥饿、醉酒、缺觉 → 决策质量断崖式下降
- 打牌是需要专注的活动，**把状态管理当成技术的一部分**
- 长期打牌：规律作息、适度运动，比多打几小时更划算
