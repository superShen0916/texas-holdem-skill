# 翻前开池范围

**适用**：无人入池，轮到你第一个加注入池（open / RFI）。
**不适用**：前面已有人入池 → 见 [`facing-raise.md`](facing-raise.md)。

数值百分比以 1326 组合为分母（见 [`reference/combinatorics.md`](../reference/combinatorics.md)），**为近似起点**，需按桌况调整。

---

## 一、按位置的开池范围

### UTG（≈15%）

| 类别 | 范围 |
| --- | --- |
| 对子 | `22+` |
| A 同花 | `ATs+`, `A5s-A2s` |
| Broadway 同花 | `KTs+`, `QTs+`, `JTs` |
| 连接同花 | `T9s` |
| 不同花 | `ATo+`, `KQo` |

### HJ（≈17%）

| 类别 | 范围 |
| --- | --- |
| 对子 | `22+` |
| A 同花 | `A9s+`, `A5s-A2s` |
| Broadway 同花 | `KTs+`, `QTs+`, `JTs` |
| 连接同花 | `T9s`, `98s` |
| 不同花 | `ATo+`, `KJo+` |

### CO（≈25%）

| 类别 | 范围 |
| --- | --- |
| 对子 | `22+` |
| A 同花 | `A2s+` |
| Broadway 同花 | `K9s+`, `Q9s+`, `J9s+` |
| 连接同花 | `T9s`, `98s`, `87s`, `76s`, `65s` |
| 不同花 | `A9o+`, `KTo+`, `QTo+`, `JTo` |

### BTN（≈43%）

| 类别 | 范围 |
| --- | --- |
| 对子 | `22+` |
| A 同花 | `A2s+` |
| Broadway 同花 | `K6s+`, `Q7s+`, `J7s+` |
| 连接 / 隔张同花 | `T7s, T8s, T9s, 97s, 98s, 87s, 86s, 76s, 75s, 65s, 54s` |
| 不同花 | `A2o+`, `K9o+`, `Q9o+`, `J9o+`, `T9o` |

### SB（≈40%，或用 limp 策略）

SB 翻后永远无位置，是全场最难打的位置。两种策略二选一：

| 策略 | 做法 | 适用 |
| --- | --- | --- |
| **raise-only** | 用接近 BTN 的范围 open，但只用能承受被 3-bet 的牌 | 对手会频繁 3-bet 时 |
| **limp 混合** | 部分牌 limp，部分牌 open | 对手在 BB 不主动加注时 |

> `[常见]` 现代主流偏向 raise-only 或"limp + 少量 open"，因对手而异。

## 二、开池尺度

| 场景 | 尺度 | 置信度 |
| --- | --- | --- |
| 线上 6-max，无人入池 | `2bb – 2.5bb` | `[共识]` |
| 线下（有抽水 + 对手爱跟） | `3bb – 5bb` | `[共识]` |
| 有 limp 者时 | `4bb + 每个 limp 者 1bb`，每个跟注者再 `+1bb` | `[共识]` |
| 有位置 vs 无位置 | 同一位置范围内**尺度保持一致**，别按牌力变化 | `[共识]` |

> **为什么不按牌力变化尺度**：尺度泄露牌力，对手能读；且保持范围不可预测性。

---

## 三、宽度直觉

| 位置 | 大致宽度 | 记忆点 |
| --- | --- | --- |
| UTG | ≈15% | 只玩真正好的牌 |
| HJ | ≈17% | 比 UTG 略宽一点 |
| CO | ≈25% | 明显放宽 |
| BTN | ≈43% | 最宽，位置就是资本 |
| SB | ≈40% | 宽但难打，宁 3-bet 勿滥跟 |

**口诀**：**每往后一个位置，放宽一档；BTN 是最宽的。**

---

## 四、对手和桌况的调整

| 桌况 | 调整 | 置信度 |
| --- | --- | --- |
| 桌上有人频繁 3-bet | 收窄开池范围，尤其是最边缘的牌 | `[共识]` |
| 桌上全是跟注站、从不加注 | 放宽开池（你几乎不会被 3-bet），但**减少纯诈唬牌** | `[共识]` |
| 多人已 limp 进入 | 整体收紧，用能打多人底池的牌（对子、同花连张） | `[共识]` |
| 短筹码（<20bb） | 见 [`facing-raise.md`](facing-raise.md) 的推推乐部分 | `[共识]` |
