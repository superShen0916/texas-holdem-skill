# 01 翻前 Preflop

翻前决定了一手牌 70% 以上的走向。这个模块收集起手牌选择与翻前行动线的经验。

## 待补充清单

- [ ] 起手牌分级：哪些牌在哪些位置能打，哪些是纯粹的陷阱
- [ ] 开池范围（RFI）：各位置的 open range 与常见偏离
- [ ] 面对 limp：隔离加注的尺度与用牌
- [ ] 面对 open：3-bet 的价值牌 / 诈唬牌配比
- [ ] 面对 3-bet：4-bet、跟注、弃牌的边界
- [ ] 盲注防守：BB/SB 防守宽度与实现权益
- [ ] 多人底池：limp 战局与多人入池的用牌收缩
- [ ] 短筹码：< 20bb 的推推乐 / 开池即全下
