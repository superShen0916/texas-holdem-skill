# 01 翻前 Preflop

翻前决定了一手牌 70% 以上的走向。这里整理起手牌选择与翻前行动线的标准打法。

翻前只需要回答三个问题：**我在什么位置、对手是什么类型、筹码有多深**。同一个 KQs 在 UTG 和 BTN 完全是两种牌。

---

## 起手牌分级

| 类别 | 例子 | 翻前价值 | 翻后怎么打 |
| --- | --- | --- | --- |
| 大对子 | AA KK QQ JJ | 最强，可 4-bet/全下 | JJ/QQ 见 A/K 要降速 |
| 中高对子 | TT-77 | 强但非坚果 | 翻中暗三才敢打大池 |
| 小对子 | 66-22 | 靠隐含赔率 | 只求翻中 set（约 1/8） |
| 大高张 | AK AQ AJ KQ | equity 高但常是"高张" | 没中就看摊牌价值 |
| 同花高张 | KQs ATs | 有听牌潜力 | 位置好可主动 |
| 同花连张 | JTs T9s 98s 87s | 靠听牌 + 隐蔽性 | 深筹码才打 |
| 垃圾牌 | K7o Q6s J4o | 纯陷阱 | 直接弃 |

**组合数（背下来，算范围时天天用）**

- 非对子每种 **16** 组合 = 4 同花 + 12 不同花
- 对子每种 **6** 组合
- 具体：AKs = 4，AKo = 12，AA = 6，AK 全部 = 16

---

## 开池范围 RFI（6-max 100bb，标准）

尺度：线上 **2~2.5bb**，线下 3bb 起。

| 位置 | 大致范围 | 宽度 |
| --- | --- | --- |
| UTG | 22+, ATs+, A5s-A2s, KTs+, QTs+, JTs, T9s, ATo+, KQo | ~15% |
| HJ | 22+, A9s+, A5s-A2s, KTs+, QTs+, JTs, T9s, 98s, ATo+, KJo+ | ~18% |
| CO | 22+, A2s+, K9s+, Q9s+, J9s+, T8s+, 98s, 87s, A9o+, KTo+, QTo+ | ~26% |
| BTN | 22+, A2s+, K2s+, Q6s+, J7s+, T7s+, 96s+, 86s+, 76s, A2o+, K9o+, Q9o+, J9o+, T9o | ~43% |
| SB | 类似 BTN，但无位置 → 略收，或用 limp 策略 | ~40% |
| BB | 不主动开池，防守用（见下） | — |

> 范围表是起点不是终点。桌上有人疯狂 3-bet 就收窄，有人从不加注就放宽。

---

## 面对 limp：隔离加注

- 尺度：**4bb + 每个 limper 加 1bb**（有人跟注再加 1bb）
- 用牌：比开池范围略紧，用能打单挑的牌（大高张、对子、同花连张）
- 目的：把烂牌挤出去，抢位置，做大底池

## 面对 open：3-bet

**尺度**
- 有位置（IP）：**3× 开池额**
- 无位置（OOP）：**4× 开池额**
- 每个跟注者再 +1×

**用牌（价值 / 诈唬配比）**
- 价值 3-bet：QQ+, AK（对手松时可加上 JJ, AQs, AKo）
- 诈唬 3-bet：选**有阻断 + 有翻后潜力**的，如 A5s-A2s（阻断 AA/AK）、KQs、76s
- 别用 ATo、KJo 去 3-bet——被 4-bet 时纯亏，翻后也难打

## 面对 3-bet

| 手牌 | 默认动作 |
| --- | --- |
| AA KK | 4-bet / 全下 |
| QQ AK | 4-bet（对手紧则跟） |
| JJ AQs TT | 有位置跟注，无位置偏弃 |
| 中小对子 | 看隐含赔率，20:1 原则（有效筹码 ≥ 跟注额 ×20 才追 set） |
| 诈唬 4-bet | A5s A4s 这类带 A 阻断的 |

> **为什么能诈唬 4-bet**：对手的 3-bet 范围里 AA/AK 占比高，你手里有 A 就说明这些组合少了一大半，对手弃牌率上升。

## 盲注防守

**BB 面对单次加注**要守得宽——已经投了 1bb，只需再付 1.5bb 就能看翻牌，底池赔率极好。
- 默认防守 ~40-50% 的范围
- 面对小尺度（2bb）守更宽，面对大尺度收窄
- 用同花、连张、带高张阻断的牌；**别用 K7o、Q8o 这种"看起来像牌"的废牌**

**SB** 没位置，是全场最难打的位置：
- 要么 3-bet，要么弃——尽量少单纯跟注
- 无 3-bet 策略时可用 limp 平衡

## 多人底池

- 入池人多 → **收紧**，因为需要更强的牌才能赢
- 对子、同花连张价值上升（能做成坚果），Axo 类高张价值下降
- 翻后诈唬频率**大幅下降**，多人底池以价值为主

## 短筹码（< 20bb）

- 进入推推乐节奏，用 **push/fold 表**而不是翻后技术
- 大致：BTN 可推 ~40%+，UTG 收紧到 ~15%
- MTT 后期这是主战场，详见 [07-formats/mtt.md](../07-formats/mtt.md)
