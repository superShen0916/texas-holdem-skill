# 工具

工具不替你做决策，但能让你**验证直觉、修正漏洞**。

> **注意**：本库是纯知识内容，**不含**任何工具、脚本或接口。以下仅为**人**做研究时可参考的工具类别。

---

## 权益计算器

手牌 vs 范围、范围 vs 范围的胜率计算。

| 工具 | 说明 |
| --- | --- |
| Equilab | 免费，经典，易用（Windows） |
| Flopzilla | 翻牌面命中率分析，做范围研究好用 |
| 在线计算器 | 搜 "poker equity calculator" |

**用途**：验证"这手牌到底有多少 equity"。**本库 [`reference/equity.md`](../reference/equity.md) 只给常见听牌与翻前对局，其余请用计算器。**

## 求解器

用 GTO 算法算最优策略，现代高水平的必修课。

| 工具 | 说明 |
| --- | --- |
| GTO+ | 性价比高，适合入门研究 |
| PioSOLVER | 老牌，功能强，价格高 |
| GTO Wizard | 云端，有训练模式，上手快 |

**用途**：研究特定牌面的下注频率与尺度；检查自己打过的牌。

> **本库的范围是"近似起点"，不是求解器精确解。** 要精确解请用求解器。

## HUD 与追踪（线上）

| 工具 | 说明 |
| --- | --- |
| Hold'em Manager 3 / PokerTracker 4 | 记录手牌 + HUD |
| 指标 | VPIP / PFR / 3-bet% / AF（定义见 [`GLOSSARY.md`](../GLOSSARY.md)） |

## 训练器

| 类型 | 说明 |
| --- | --- |
| GTO Wizard 训练 | 范围记忆、节点决策演练 |

---

## 选工具的原则

1. 先把基础打对，工具只是加速器
2. 求解器用来**理解原理**，不是背答案
3. **复盘 > 学新东西**（自己的漏洞最值钱）
4. 别陷入"工具收集癖"
