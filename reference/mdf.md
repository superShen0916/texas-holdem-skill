# MDF 与 Alpha 表

> 面对下注"我至少要防守多少比例，才不让对手随便诈唬都赚钱"。**查这里，不要自己算。**

---

## 定义

- **MDF（最低防守频率）** = 底池 ÷ (底池 + 下注额) = `1 / (1 + b)`
- **Alpha** = 对手诈唬的盈亏平衡所需弃牌率 = `1 − MDF` = `b / (1 + b)`

其中 `b` = 对手下注额 ÷ 底池。

---

## 数值表

| 对手下注 | **MDF：你至少要继续** | **Alpha：对手需要你弃牌** |
| --- | --- | --- |
| 1/4 池 | **80.0%** | 20.0% |
| 1/3 池 | **75.0%** | 25.0% |
| 1/2 池 | **66.7%** | 33.3% |
| 2/3 池 | **60.0%** | 40.0% |
| 3/4 池 | **57.1%** | 42.9% |
| 满池 | **50.0%** | 50.0% |
| 1.5 倍池 | **40.0%** | 60.0% |
| 2 倍池 | **33.3%** | 66.7% |

**速记**：对手下小注（1/3 池）→ 你要守 **75%**，几乎不能弃；对手下满池 → 守 **50%**，可以弃一半。

> Alpha 列与 [`pot-odds.md`](pot-odds.md) 第二节的"需要对手弃牌"是同一组数。

---

## 怎么用

1. 看对手下注相对底池的比例，查出 MDF
2. 从你的**整个范围**里，挑出至少这个比例的牌继续（最强的 + 有听牌的，按强弱往下取到 MDF 线）
3. 剩下的可以弃

> 直觉：**对手下得越小，你越不该弃**；对手下得越大，你越可以多弃。

---

## 重要限制（别机械套用）

MDF 是**理论基准**，成立的前提是"对手会用足够的诈唬来惩罚你过度弃牌"。实战中：

| 情况 | 该怎么调整 |
| --- | --- |
| 对手**几乎不诈唬**（跟注站、被动型） | **可以弃得比 MDF 多得多**——他没在诈唬，你不需要防守那么宽 |
| 对手**诈唬过多**（疯子） | **守得比 MDF 更宽**，用更边缘的牌跟注 |
| 多人底池 | MDF 概念减弱，以实际牌力为主 |
| 你已无位置且对手强 | 可以低于 MDF，因为你的实现权益打折 |

**原则**：`[数学]` MDF 是默认线；`[经验]` 一旦读出对手倾向，就该偏离它。偏离的依据写进 [`05-exploits/`](../05-exploits/exploits.md)。
