# 底池赔率与弃牌权益表

> **本表是全库唯一的赔率数值来源。** 需要"该不该跟""诈唬成本多少"时，查这里，不要自己算。

---

## 一、面对下注：跟注需要多少胜率

设底池为 `P`，对手下注 `b × P`。

**公式**：所需胜率 = 跟注额 ÷ (底池 + 对手下注 + 跟注额)

| 对手下注 | 你需要跟 | 下注后底池 | **所需胜率** |
| --- | --- | --- | --- |
| 1/4 池 | 0.25P | 1.5P | **16.7%** |
| 1/3 池 | 0.33P | 1.67P | **20.0%** |
| 1/2 池 | 0.5P | 2.0P | **25.0%** |
| 2/3 池 | 0.67P | 2.33P | **28.6%** |
| 3/4 池 | 0.75P | 2.5P | **30.0%** |
| 满池 | 1.0P | 3.0P | **33.3%** |
| 1.5 倍池 | 1.5P | 4.0P | **37.5%** |
| 2 倍池 | 2.0P | 5.0P | **40.0%** |

**速记**：1/3 池 → 20%，1/2 池 → 25%，满池 → 33%。

**怎么用**：拿你的胜率（查 [`equity.md`](equity.md)）和"所需胜率"比。
- 你的胜率 **>** 所需 → 跟注在赔率上有利
- 你的胜率 **<** 所需 → 弃牌（除非隐含赔率能补上，见下）

> 对手下注比例不在表内 → 取**最接近**的档位，并说明"这是近似值"。

## 二、诈唬：需要对手弃牌多少比例

**公式**：盈亏平衡弃牌率 = 下注额 ÷ (下注额 + 底池)

| 你的下注 | **需要对手弃牌** |
| --- | --- |
| 1/4 池 | **20.0%** |
| 1/3 池 | **25.0%** |
| 1/2 池 | **33.3%** |
| 2/3 池 | **40.0%** |
| 3/4 池 | **42.9%** |
| 满池 | **50.0%** |
| 1.5 倍池 | **60.0%** |
| 2 倍池 | **66.7%** |

**怎么用**：估计对手实际弃牌率，和目标比。
- 他弃得 **>** 目标 → 诈唬有利
- 他弃得 **<** 目标 → 别诈唬

> 这张表和 [`mdf.md`](mdf.md) 的 Alpha 是同一个数——本质是同一个公式。

## 三、多想一层：隐含赔率

底池赔率只看**当前**。当你的牌成牌后还能从对手那里再赢钱时，实际赔率比表里的好。

**用在**：暗三（翻中概率约 1/8）、坚果听牌、对手还有筹码且会付钱。

**经验法则**：追纯暗三，要求**有效筹码 ≥ 跟注额 × 20**。

> 但注意**反向隐含赔率**：你成牌了仍是第二好（如 K7 中顶对），反而输更多。

---

## 四、多人底池的注意点

跟注所需胜率的公式**不变**，但：

- 底池更大 → 表里的百分比更容易满足
- 然而你的**实际胜率会随人数下降**——对手越多，你的牌被超过的概率越高
- 两边都要考虑，不能因为"底池大"就无脑跟

---

## 五、本表未覆盖的情况

- 有多个对手、且下注情况复杂（如一家下注一家跟注）→ 逐次计算超出本表，说明不确定
- 比赛中的 ICM 影响 → 见 [`07-formats/mtt.md`](../07-formats/mtt.md)
- 任何需要精确求解的判断 → 本表是**近似起点**，不是精确解
