# SPR 与底池几何表

> "这副牌能不能打光""该下多大才能把筹码全进池"。**查这里，不要自己推。**

---

## 定义

**SPR = 有效筹码 ÷ 翻牌后的底池**

有效筹码 = 你和对手中较短的那一份。

---

## 一、SPR 策略档位

| SPR | 含义 | 什么牌才敢打光 |
| --- | --- | --- |
| < 1 | 极浅 | 任何对子、任何听牌都可以全下 |
| 1 – 3 | 浅 | **顶对**即可打光 |
| 3 – 6 | 中 | 顶对强踢脚 / 两对 |
| 6 – 10 | 标准 | **两对以上** |
| > 10 | 深 | 只有坚果级（三条、顺子、同花以上）才玩大池 |

**核心口诀：SPR 越低，对牌力的要求越低。**

---

## 二、底池几何：打光需要多少 SPR

问：我想用**每街相同的比例**把筹码全部打进池，需要多大的 SPR？

| 下注计划 | 打光需要 SPR |
| --- | --- |
| 翻牌一次满池 | 1.0 |
| 三街 1/3 池 | 1.8 |
| 两街 2/3 池 | 2.2 |
| 翻牌 1/2 → 转牌满池 | 2.5 |
| 两街 3/4 池 | 2.6 |
| 三街 1/2 池 | 3.5 |
| 两街满池 | 4.0 |
| 三街 2/3 池 | 5.9 |
| 三街 3/4 池 | 7.3 |
| 三街满池 | 13.0 |

**怎么用**：
1. 算出当前 SPR
2. 反查表：这个 SPR 用哪条计划刚好打光
3. 按那条计划的每街比例下注

> **示例**：翻牌后 SPR = 4。查表 → **两街满池**刚好打光。所以翻牌和转牌各下满池即可。

---

## 三、怎么算 SPR

1. 翻前结束时确定底池 `P`
2. 取双方剩余筹码的**较小值** `S`（这就是有效筹码）
3. `SPR = S ÷ P`
