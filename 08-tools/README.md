# 08 工具 Tools

工具不能替你做决策，但能让你**验证直觉、修正漏洞**。

---

## 权益计算器（Equity Calculator）

手牌 vs 范围、范围 vs 范围的胜率计算。

- **Equilab**（Windows 免费）——老牌经典，易用
- **Flopzilla**——翻牌面命中率分析，做范围研究很好用
- **在线计算器**——搜 "poker equity calculator" 即可，应急够用

**用途**：验证"这手牌到底有多少 equity"、算听牌胜率。

## 求解器（Solver）

用 GTO 算法算出每个节点的最优策略。**现代高水平的必修课**。

- **GTO+**——性价比高，适合入门研究
- **PioSOLVER**——老牌，功能强大，价格高
- **GTO Wizard**——云端，有训练模式和现成方案，上手快
- **Simple Postflop**——另一选择

**用途**：
- 研究特定牌面的下注尺度与频率
- 检查自己打过的牌，和 GTO 对比找漏洞
- **注意**：求解器输出是"基准"，实战要针对对手偏离

## HUD 与追踪（线上）

- **Hold'em Manager 3** / **PokerTracker 4**——记录手牌 + HUD 显示
- 显示 VPIP / PFR / 3-bet% / AF 等
- **注意**：很多平台禁止或限制 HUD，用前先看清规则

## 手牌记录与复盘

- **截图 + 笔记**：最简单也最有效
- **HM/PT** 的复盘功能：筛选手牌、看统计
- **Notion / 表格**：自建记录（本仓库就是个例子）

## 训练器

- **GTO Wizard 训练**：范围记忆、节点决策演练
- **Push/fold 训练**：背 ICM 推推乐范围
- **范围记忆 App**：练开池 / 3-bet 范围

## 自建工具

- **范围表**：把标准范围做成可查的表格 / 图
- **ICM 计算器**：决赛桌决策可用
- **脚本**：会写代码的话，批量分析手牌历史很划算

---

## 选工具的原则

1. **先把基础打对**，工具只是加速器
2. 求解器用来**理解原理**，不是背答案
3. 复盘 > 学新东西（自己的漏洞最值钱）
4. 别陷入"工具收集癖"——一个求解器 + 一个计算器就够开始
