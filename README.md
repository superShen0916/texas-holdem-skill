# Texas Hold'em Skill

德州扑克各种玩法的经验与技巧笔记。

目标是把零散的实战体感整理成可复用的 checklist：**什么位置、什么牌、什么对手、做什么动作、为什么**。

## 笔记格式

每条经验建议按这个结构写，方便回查和验证：

```markdown
### 一句话结论
（能直接执行的规则）

**场景**：位置 / 筹码深度 / 对手类型 / 行动线
**理由**：为什么这么做，基于什么原理
**反例 / 边界**：什么情况下这条不成立
**来源**：实战复盘 / 某本书 / 求解器跑出来的
```
